# Extras

some extra information regarding credits/inspiration, useful websites/resources, guides on how to contribute etc

good crafting recipe visual generator: [Crafting Generator](https://crafting.thedestruc7i0n.ca/)

how i draw the pixel art: [LibreSprite](https://libresprite.github.io/)

how i make block models and the title: [Blockbench](https://www.blockbench.net/) and [Title Plugin](https://ewanhowell.com/plugins/minecraft-title-generator/) (for the "Herbalis" title in the readme i used font `Minecraft Ten`, texture `Grass`, variant `Flowers`, overlay `Cartoon`)

how i make image modifications: [paint.net](https://www.getpaint.net/)

the modrinth mod/project description used to be: `Minecraft mod that adds real-life herbs, teas, and natural remedies, letting you collect, process, and craft your way from folk medicine to advanced treatments like antibiotics.`
